What to try

Every combination should cost one request. What each one cost before the fix:

  • 3 observers · staleTime 60 s — one request per observer, each cancelling the previous observer's one.
  • 1 observer · staleTime 0 — a second request as soon as the first resolved.
  • 3 observers · staleTime 0 — both at once.
  • 1 observer · staleTime 60 s — one request: the only combination that was already right.
