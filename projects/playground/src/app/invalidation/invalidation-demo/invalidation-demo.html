What to try
  • 3 observers · staleTime 60 s — the bug from the issue: each observer fires its own request and cancels the previous observer's one.
  • 1 observer · staleTime 0 — no cancellations, but a second request starts as soon as the first resolves.
  • 3 observers · staleTime 0 — both at once.
  • 1 observer · staleTime 60 s — the only combination that costs one request today.
